## 项目一：端到端房价预测与模型部署

这是从 Kaggle 房价数据集走完的「数据 → 模型 → API」全流程项目。

### 数据清洗与特征工程

原始数据缺失值多、类别特征杂，这一步花的时间最长：

- 用 Pandas/NumPy 做缺失值填充和异常值处理，数值特征和类别特征分开对待。
- 通过 Matplotlib/Seaborn 可视化分析特征与目标的相关性，辅助筛选特征，剔除冗余。
- 对偏态分布的目标变量做对数变换，让模型更好拟合。

### 建模与调参

- 基线上用 `scikit-learn` 的线性模型和树模型做对比，确认树模型在非线性特征上更占优。
- 最终选用 **XGBoost** 作为主模型，并构建**堆叠集成**——底层多个模型（XGBoost、LightGBM、岭回归等）各自的预测作为新特征，喂给上层融合模型，取长补短。
- 用交叉验证统一评估，再结合网格搜索 + 随机搜索做参数调优，把模型精度（RMSE）提升到了 **0.0337**。
- 这里的关键不是「调出一个最好的参数」，而是建立一套**可复现的评估流程**——每次改动都跑同样的验证，才知道到底有没有变好。

### 部署

用 Flask 把模型封装成 `POST /predict` API 接口：加载训练好的模型权重，把特征预处理（对数变换、类别编码）封装成**与训练时完全一致的管道**，请求进来先转换再预测，返回 JSON 结果，实现实时预测。这是把「数据科学」变成「可用产品」的关键一步。

## 项目二：客户价值分析（RFM + K-Means）

电商场景里，不是所有用户都值得花同样的营销资源。这个项目要回答：**哪些用户是高价值的？**

### RFM 模型

RFM 是经典的客户价值评估框架：

- **R（Recency）**：最近一次购买距今多久
- **F（Frequency）**：购买频率
- **M（Monetary）**：消费金额

我完成数据预处理和异常值处理后，按分位数把 R / F / M 各映射成 1–5 分，得到每个用户的 RFM 三元评分——比如一个用户是「R=5, F=3, M=5」，说明他最近刚买过、频率中等、消费额很高。并在此基础上设计了**动态权重算法**，根据消费行为特征调整三个维度的权重，而不是套用固定模板。

### 聚类分群

对 RFM 评分做标准化后，用 **K-Means 聚类**把客户分成若干群体，用肘部法则确定聚类数并验证区分度，再回到业务视角给每个群体画像：高价值核心用户、潜力用户、需要唤醒的流失风险用户。

### 结果

最终精准识别出占总用户数 **15%** 的高价值群体，这个群体贡献了公司约 **60%** 的营收——典型的「二八法则」在客户结构上的体现。据此撰写了可视化分析报告，为精准营销提供了数据支撑。

## 方法论总结

这两个项目走下来，沉淀下几条通用的做事方式：

1. **数据先行**：模型效果的上限由数据质量决定，特征工程花再多时间都值。
2. **评估闭环**：任何改动都跑同一套验证流程，用数字说话，不凭感觉。
3. **业务收尾**：分析结果要落到业务语言上（「15% 用户贡献 60% 营收」比「聚类得到 4 类」有意义得多）。
