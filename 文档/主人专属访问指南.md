# 主人专属访问指南

> 你（博主）专属的 3 个页面，访客完全看不到、用不了，聊天和评论照旧。
> 识别你的钥匙 = 后端 `.env` 里的 `OWNER_SECRET`。

---

## 一、你的钥匙在哪

打开 `backend/.env`，找到这行，等号后面那一串就是钥匙：

```
OWNER_SECRET=你的钥匙
```

> 钥匙别发到网上、别传给别人；想要换一把就改 `.env` 再重启后端。

## 二、怎么进（首选：导航栏 👑 主人按钮）

打开任意页面，**右上角始终有一个「👑 主人」按钮**（访客也能看到它，但没钥匙点不进去）：

```
1. 点右上角「👑 主人」
2. 输入 OWNER_SECRET，点「进入」
3. 登录成功后：💬 私聊 / ⚙️ 管理 / ✍️ 发布 三个标签**直接出现在导航栏上**，跟「首页」「关于」并排，随时一点直达
```

- 钥匙只存**你本机的浏览器**（localStorage），三个页面通用，**只输一次**；
- 之后每次打开网站都是登录态，切换任何页面（首页/图库/文章/私聊）都不丢，不用再输；
- **不输钥匙就永远看不到这三个标签**——访客只有「首页 / 图库 / 关于」；
- 登录后右上角按钮变成「👑 主人·已登录」并带一个**萤火绿小点**，一眼就知道还登着（点它可退出）；
- 点「🚪 退出登录」清掉钥匙后，三个标签随之消失，回到访客样子。

## 三、备选：带钥匙访问（一次搞定）

在地址后面拼 `?owner_token=钥匙`，回车：

```
http://localhost:3000/#/chat?owner_token=钥匙      # 主人私聊：跟萤宝聊天
http://localhost:3000/#/admin?owner_token=钥匙     # 管理后台：数据 + 系统运行信息
http://localhost:3000/#/write?owner_token=钥匙     # 发布文章：md 编辑器
```

（把「钥匙」换成 `.env` 里那一串。）

带钥匙打开一次后，钥匙同样自动存入浏览器、地址栏自动变干净，之后直接点「👑 主人」就能进。

## 三、也可以手输登录

不带参数打开任意页面，在输入框里手输 `OWNER_SECRET` 一样能进。

## 四、三个页面是干嘛的

| 页面 | 用途 |
|------|------|
| `#/chat` | 主人私聊：好感度满级、长期记忆、人格演化全开 |
| `#/admin` | 管理后台：数据统计 + **文章管理**（全量文章，可删除）+ **评论管理**（全量评论含私密，可删除）+ 人格印象 + 系统运行信息（版本/运行时长/错误数/主机/PID/数据库大小） |
| `#/write` | 发布文章：填标题/分类/标签/Markdown 正文，发布即对访客可见、自动进知识库 |

## 五、部署到云端后

把 `localhost:3000` 换成你的域名即可，方法一模一样：

```
https://你的域名/#/chat?owner_token=钥匙
https://你的域名/#/admin?owner_token=钥匙
https://你的域名/#/write?owner_token=钥匙
```

钥匙在 `#` 后面，不会出现在服务器访问日志里。

## 六、访客看到什么

- 主页、文章、图库、右下角聊天、评论：和原来一模一样；
- 导航栏只有「首页 / 图库 / 关于」，**没有** 私聊 / 管理 / 发布；
- 右上角有一个「👑 主人」按钮，但里面只有输钥匙的框——没钥匙永远进不去；
- 私聊 / 管理后台 / 发布文章 三个页面即使被猜到地址，也会被后端鉴权挡下（401）。
