## 八、性能优化（2026-08-12 追加）

| 问题 | 修复 |
|------|------|
| 满屏玻璃卡片 `backdrop-blur-xl`（24px）叠加在**每帧动画的全屏 canvas** 上，且侧栏为 `sticky` 定位，滚动时每个玻璃元素都要对移动中的背景逐帧重采样模糊 | `.glass-card` / `.glass-input` **移除 backdrop-filter**，改用更高不透明底色 + 顶部萤光高光渐变呈现玻璃质感（视觉几乎不变，滚动不再逐帧重采样）；ChatWidget 窗、聊天气泡、评论区、右栏收起按钮同步移除；NavBar 由 `backdrop-blur-xl` 降为 `backdrop-blur-md` 并提高底色不透明度 |
| body `background-attachment: fixed`（已知滚动重绘陷阱） | 移除，渐变随内容自然滚动 |
| 粒子 canvas：逐粒子 `shadowBlur`（开销极高）、DPR 上限 2、全量 60fps 永不停 | 预渲染光点贴图（`drawImage`）+ `globalCompositeOperation: lighter`、DPR 上限降到 1.5、**30fps 节流**、**后台标签页自动暂停**、粒子数上限 70→50 |
| Live2D 角色持续 60fps 渲染 | 加 `powerPreference: high-performance`、**后台标签页暂停/恢复**、30fps 节流、光环粒子数略减 |

## 九、Bug 修复（2026-08-12 追加）

**文章详情页上下篇切换不刷新**：`/article/:id` 内点击「上一篇/下一篇」后地址栏变化但内容不刷新（需 F5）。
- 根因：路由复用同一组件实例，`onMounted` 不会重跑，文章数据未重新拉取；`slugCounts`（标题锚点 id 去重计数）也在模块作用域跨文章累积。
- 修复（`frontend/src/views/Article.vue`）：抽 `loadArticle(id)`，`onMounted` 首载 + `watch(articleId)` 路由参数变化时重载；带**竞态保护**（快速连点时旧请求不覆盖新内容）；渲染前重置 `slugCounts`；切换时回到页首。
- 评论区（`CommentSection.vue`）跟随 `articleId` 变化重新拉取该文章评论并清空表单。
- 目录锚点（`RightSidebar.vue`）：hash 路由下普通 `<a href="#id">` 会把路由改成 `/id` 导致页面失效，改为 `@click.prevent` + `scrollIntoView({ behavior: 'smooth' })` 页内平滑滚动；正文标题加 `scroll-margin-top` 避开吸顶导航。
- 新增回归测试 `src/views/__tests__/Article.test.js`（加载/占位/上下篇切换重载/切回），全量 17 文件 / 97 用例通过，`npm run build` 通过。

## 十五、后端：知识库自动更新 KB Watcher（2026-08-12 追加）

针对「只在写新文章/修改文章时更新，其他时候零动作，服务器常驻不频繁重启」：

- **`backend/modules/kb_watcher.py`（新增）**：后台守护线程，每 10 秒轮询。
  - 首轮只记录所有文章 `mtime` 基线，**不做任何更新**；
  - 之后检测到「新增 / 修改」且文件**写稳 60 秒**（`SETTLE_SECONDS`，避免索引编辑到一半的半成品）才增量入向量库；
  - 更新时打印「KB 已自动更新 N 篇文章」清单（每篇 `[新增/修改] 标题（id）`）。
- **`backend/modules/chat/rag.py`**：抽出 `_prepare/_add`，新增 `upsert_articles()`（`collection.upsert` = 新增或覆盖，同 id 幂等）、`indexed_ids()`。
- **`backend/modules/articles/loader.py`**：新增 `articles_dir` / `file_mtime(article_id)`。
- **`backend/app.py`**：`__main__` 调用 `start_kb_watcher(app)`；debug 重载器下只在子进程启动（`WERKZEUG_RUN_MAIN` 判断），避免双线程。
- 效果：写新文章 / 改文章后**无需手动 `manage.py reindex`**，问答自动读到新内容。

## 十八、主人专属功能：私聊 / 管理后台 / 发布文章 + 令牌特殊访问（2026-08-12 追加）

针对「仅我自己访问时有私聊与后台、访客体验完全不变、我有专属发布文章入口、部署到云端后我怎么身份识别」。

**令牌特殊访问方式（主人唯一入口，访客无从得知）**
- 部署后在任意页面地址后拼 `?owner_token=<OWNER_SECRET>`，如：
  `https://你的域名/#/chat?owner_token=你的密钥`、`…/#/admin?owner_token=你的密钥`、`…/#/write?owner_token=你的密钥`
- 访问时 **App.vue 全局读取该参数 → 写入浏览器 localStorage → 自动从地址栏清除**（hash 路由下令牌在 `#` 片段内，不进服务器访问日志 / Referer）；之后每次打开页面都已是登录态，无需再输密钥。
- 密钥即后端 `.env` 里的 `OWNER_SECRET`，只存你本机浏览器，不进前端代码 / git。
- 访客访问主页：**看不到任何登录入口**（NavBar 的「私聊」、侧栏的「管理 / 写新文章」均只在本地有令牌时才显示），聊天窗、评论等原有功能与之前完全一致。

**新增前端**
